✨ TÍNH NĂNG MỚI:

1. ✅ PER-TOPIC DEPLOYMENT
   • Mỗi topic có thể chạy như 1 Spark job riêng
   • Isolation: Lỗi ở 1 topic không ảnh hưởng topics khác
   • Debug dễ: Log riêng, Spark UI riêng
   
   Usage:
   spark-submit main.py --app-name my_app --topic-name orders

2. ✅ MODULAR SCHEMA PROCESSING
   • Tách schema logic ra khỏi ETL job chính
   • Dễ dàng tạo custom processor cho topics đặc biệt
   • Factory pattern tự động chọn processor phù hợp
   
   Example:
   class MyProcessor(BaseSchemaProcessor):
       def get_data_schema(self, topic_config):
           return custom_schema

3. ✅ PATTERN MATCHING
   • Support wildcard để register processor cho nhiều topics
   • Example: 'orders_*' matches orders_v1, orders_v2, etc.

4. ✅ DEPLOYMENT AUTOMATION
   • Scripts để deploy nhiều topics tự động
   • Windows: deploy_per_topic.ps1
   • Linux/Mac: deploy_per_topic.sh

🚀 CÁCH SỬ DỤNG:

[Option 1] Chạy 1 topic:
    spark-submit main.py --app-name my_app --topic-name orders

[Option 2] Deploy nhiều topics:
    .\deploy_per_topic.ps1 -AppName "my_app" -Topics "t1,t2,t3"

[Option 3] Custom processor:
    1. Create: core/schema_processors/custom/my_processor.py
    2. Register: SchemaProcessorFactory.register_processor(...)
    3. Run: spark-submit main.py --topic-name my_topic
